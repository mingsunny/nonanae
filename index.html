Settle — walkthrough

Static prototype, fake data, no backend. Use this script when reviewing with a coworker:

  1. Log in (any info) — or tap Sign up to see that screen too
  2. Open the pre-loaded SF Trip group and browse its expenses
  3. Tap Settle Up to see the minimized who-pays-whom breakdown
  4. Go back to the Trips tab, tap + to create a new trip from scratch
  5. Add an expense, try each split type (equal / exact / % / shares)
  6. Use + Invite on the trip screen to add friends any time — it's not required up front
  7. Mark yourself done, then use the demo control to mark everyone else done
  8. Check the Activity tab for the notification, then view settlement
  9. Tap the Profile tab to see the account screen
