# 08. 그룹 지출 내역

> 그룹 내부 화면의 기본(첫 진입) 탭. 탭 순서: 지출(08) → 정산(09) → 요약(10).

그룹(여행) 안에서 지금까지 등록된 지출을 날짜별로 훑어보고, 새 지출을 빠르게 추가하는 메인 화면.

- **담당자**:
- **상태**: 초안

## 1. 화면 개요

| 항목 | 내용 |
|---|---|
| 화면 ID | 08_group_expense_list |
| 역할 | 그룹 내 지출 조회 + 새 지출 등록 진입점 (그룹 상세 기본 탭) |
| 진입 경로 | 03 그룹 목록에서 그룹 선택(기본 탭), 그룹 내부 하단 탭바 "지출" 선택, 13 알림에서 알림 항목 탭 |
| 다음 화면 | 11 지출 추가/수정 폼, 12 멤버 초대(목록) |
| 같은 그룹 내 탭 전환 | 09 정산, 10 요약 |

## 2. 진입 조건

- 로그인 + 계좌 등록 완료(02 온보딩)한 사용자
- 이 그룹의 멤버(group_members)로 등록되어 있을 것

## 3. UI 구성

### 3.1 헤더 — 08/09/10 세 탭 공용

- 그룹명, 총 사용 금액 상시 노출
- 멤버 아바타 줄 탭 → 12 멤버 목록으로 이동
- "멤버 초대" 버튼 탭 → 12 멤버 초대(목록) 화면으로 이동 (실제 카카오톡 발송은 12에서 처리)
- "초대 코드 복사" 버튼 탭 → 화면 이동 없이 초대코드를 클립보드에 복사 + 토스트

### 3.2 지출 목록

- 날짜(dateLabel) 단위로 묶어서 표시, 최신 등록 건이 위로 오도록 정렬
- 날짜 라벨 자체는 재정렬하지 않고 지출이 나타나는 순서를 따름

### 3.3 개별 지출 항목 (영수증 카드)

- 카테고리 배지(아이콘/색상), 항목명, 금액(우측 정렬)
- 서브 텍스트: "{결제자} 결제 · N명 나눔" (참여자가 전체보다 적으면 "(일부)" 추가)
- 카드 탭 → 11 지출 폼이 수정 모드로 열림(기존 값 프리필)

### 3.4 가이드 (빈 상태)

| 조건 | 문구 | 강조 |
|---|---|---|
| 멤버 1명(나만 있음), 지출 0건 | "정산할 친구를 초대해주세요." | — |
| 멤버 2명 이상, 지출 0건 | "아직 등록된 지출이 없어요. 첫 지출을 추가해보세요." | FAB(＋)에 글로우 애니메이션(guide-target) |

### 3.5 FAB

- 우하단 고정 "＋" 버튼 → 11 지출 폼이 신규 등록 모드로 열림

## 4. 기능

| 기능 | 동작 |
|---|---|
| 지출 카드 탭 | 11 지출 폼 수정 모드로 이동 |
| FAB 탭 | 11 지출 폼 신규 등록 모드로 이동 |
| 헤더 "멤버 초대" | 12 멤버 초대 화면으로 이동 |
| 헤더 "초대 코드 복사" | 초대코드 클립보드 복사 + 토스트 |
| 헤더 back | 전역 홈(그룹 목록)으로 이동 |

## 5. 데이터

- `expenses`: id, group_id, title, amount, category, payer_id, participant_ids, date_label, receipt_image_url, split_type, custom_shares
- `group_members`: 결제자/참여자 이름 표시에 사용
- 정렬: 신규 등록 지출이 목록 맨 앞에 추가되어 최신순 유지

## 6. 예외 처리

| 상황 | 처리 |
|---|---|
| 지출 0건 + 멤버 1명 | "친구 초대" 안내만 노출 (지출 추가 안내와 동시 노출 안 함) |
| 지출 0건 + 멤버 2명 이상 | "첫 지출 추가" 안내 + FAB 강조 |
| 결제자 정보를 찾을 수 없음 (정상 흐름에서 발생 안 함) | "알 수 없음"으로 방어적 표시 |
