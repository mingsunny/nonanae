# 01. 로그인

> ⚠️ 로그인 방식(카카오 소셜 로그인 / 자체 회원가입·이메일 로그인 등)은 아직 최종 확정되지 않음. 현재 프로토타입 HTML은 카카오 로그인 UI로 구현되어 있지만, 방식이 확정되기 전까지 이 문서는 **일반화된 "유저 ID" 기반 로그인**으로 가정하고 작성함. 최종 로그인 방식이 정해지면 이 문서, [schema.md](schema.md#user)의 `userId` 필드, [02-onboarding.md](02-onboarding.md)를 함께 갱신해야 함.

- **담당자**: 민선
- **상태**: 작성중

## 목적

앱을 사용하기 위해 사용자를 식별하고, 이후 정산 데이터(그룹/지출)를 특정 사용자에 귀속시키기 위한 최초 진입 화면.

## 주요 기능

- 유저 ID로 로그인 시도 (구체적 입력 수단은 로그인 방식 확정 후 결정)
- 로그인 처리 중 로딩 상태 표시
- 로그인 성공 시 신규 / 기존 사용자 여부에 따라 다음 화면 분기

## 진입 경로

- 앱을 처음 실행했을 때 진입하는 시작 화면. 별도 진입 경로 없음 (최초 화면)

## UI 구성요소

- 타이틀: 서비스명
- 안내 문구 (guide-callout)
- 로그인 버튼 — 유저 ID 기반으로 가정 (실제 UI/입력 필드 구성은 로그인 방식 확정 후 결정)

### 로그인 처리 중 (로딩 상태)

- 로그인 시도 후 짧게 노출되는 로딩 스피너 화면 (현재 프로토타입 기준 약 0.7초 뒤 자동 진행)

## 데이터

- 로그인 식별에 사용하는 값: `User.userId` (가칭). [schema.md](schema.md#user) 참고 — 로그인 방식이 미확정이라 기존 `kakaoId` 필드를 범용 `userId`로 변경함
- 로그인 성공 시 `userId` 기준으로 기존 가입자 여부를 조회하여 신규 / 기존 사용자로 분기

## 액션 & 결과

| 액션 | 결과 |
|---|---|
| 로그인 시도 | 로딩 화면으로 전환 → 처리 완료 후 `userId` 기준으로 기존/신규 사용자 분기 |
| 기존 사용자로 확인됨 | 온보딩을 건너뛰고 [03-group-list.md](03-group-list.md)로 바로 이동 |
| 신규 사용자로 확인됨 | [02-onboarding.md](02-onboarding.md) (계좌 등록)로 이동 |

## 예외처리

- 로그인 방식이 확정되지 않아 아이디 형식 검증, 비밀번호 유무, 소셜 로그인 실패 처리 등 구체적인 예외 케이스는 정의를 보류함
- 로그인 처리 실패(네트워크 오류 등) 시 UX는 현재 프로토타입에 정의돼 있지 않음 — 추후 결정 필요
