# 04. 프로필 (그룹 목록 화면 내 탭)

> 그룹 목록 화면(03) 하단 탭바의 "프로필" 탭. 로그인한 내 정보(이름/은행/계좌) 수정, 로그아웃, 회원탈퇴를 다룸.

> ⚠️ **게스트 참가자는 이 화면에 대응하는 화면이 없음.** [03-group-list.md](03-group-list.md)와 마찬가지로 게스트는 하단 탭바 자체가 다름(홈/프로필 없이 그룹 내부 탭만 존재). 게스트의 닉네임은 `User` 레벨이 아니라 `GroupMember.nickname`으로 그룹별로 저장되므로, "내 정보 수정"이라는 개념이 정식 회원과 동일하게 적용되지 않음 — 게스트가 닉네임을 바꾸고 싶을 때 어디서 어떻게 바꾸는지는 아직 정의되지 않음(열린 항목). 또한 게스트 → 정식 회원 전환 진입점을 이 화면에 둘지, 그룹 내부 화면에 둘지도 미정 — 게스트 관련 화면을 설계할 담당자가 결정 필요. 배경: [PLAN-sep03-yunjung.md](../../PLAN-sep03-yunjung.md) "결정된 질문 9" 참고. (게스트의 PIN 인증 여부 자체가 sep10 기준 미확인 상태 — [06-join-group.md](06-join-group.md) 참고)

- **담당자**: 민선
- **상태**: 작성중

## 목적

로그인한 **정식 회원**이 자신의 이름 / 은행 / 계좌번호를 확인하고 수정할 수 있게 하고, 로그아웃 및 회원탈퇴 진입점을 제공하는 화면.

> ✅ 로그인 방식 확정 (2026-09-12, sep10 기준): 이메일+비밀번호만 지원, 구글·카카오 연동 로그인은 스펙에서 제외됨 ([01-login.md](01-login.md) 참고). 모든 계정이 이메일 기반이라 계정 유형별 분기나 연동 계정 관리 UI는 필요 없음.

## 주요 기능

- 현재 로그인한 사용자 정보(아바타, 이름) 표시
- 이름 / 은행 / 계좌번호 수정
- 로그아웃
- 회원탈퇴

## 진입 경로

- [03-group-list.md](03-group-list.md) 화면 하단 탭바에서 "프로필" 탭 클릭 (`setGroupsTab('profile')`) — 별도의 화면 전환이 아니라 같은 `screen-groups` 안에서 탭만 바뀜

## UI 구성요소

- 프로필 요약 카드: 아바타(이름 첫 글자, `pf-avatar`), 이름(`pf-name-display`), 부가 설명 텍스트("이메일 계정으로 로그인함" — 고정 문구, 계정 유형이 이메일 하나뿐이라 분기 없음)
- 이름 입력 필드 (`pf-name`, text, 현재 값으로 사전 채움)
- 은행 선택 (`pf-bank`, select) — [공통 은행 목록](conventions.md#은행-목록), 현재 은행이 기본 선택됨
- 계좌번호 입력 필드 (`pf-account`, text, 현재 값으로 사전 채움)
- "저장하기" 버튼 (`pf-save-btn`) — 탭 진입 시 기본 disabled, 이름/은행/계좌 **세 필드가 모두 채워져야** 활성화
- 하단 텍스트 링크 2개: "로그아웃", "회원 탈퇴"

## 데이터

- 대상: 현재 로그인한 `User`(`state.currentUser`)의 `name`, `bank`, `account` 필드 ([schema.md](schema.md#user) 참고)
- 그룹의 `members` 배열에는 사용자 객체가 값 복사가 아니라 **참조로** 들어가므로, 여기서 프로필을 수정하면 내가 속한 모든 그룹의 멤버 표시에도 즉시 반영됨
- 저장 시 그룹 목록 화면 상단 인사말(`groups-greeting`)도 새 이름으로 함께 갱신됨

## 액션 & 결과

| 액션 | 결과 |
|---|---|
| 이름 / 은행 / 계좌 중 하나라도 값 변경 | 세 필드가 모두 채워졌는지 검사해 "저장하기" 버튼 활성/비활성 갱신 |
| "저장하기" 클릭 | `saveProfile()` 실행 → `state.currentUser` 갱신 → 그룹 목록 인사말 갱신 → "프로필이 저장되었습니다" 토스트 → 저장 버튼 다시 disabled |
| "로그아웃" 클릭 | 확인 절차 없이 즉시 `state.currentUser = null` → [01-login.md](01-login.md)로 이동 |
| "회원 탈퇴" 클릭 | 브라우저 기본 확인창("정말 탈퇴하시겠어요? 계좌 정보가 삭제돼요.") → 확인 시 계정 삭제 후 [01-login.md](01-login.md)로 이동 |

## 예외처리

- 로그아웃은 별도 확인 절차 없이 즉시 처리됨 (실수 클릭 방지 장치 없음)
- 회원탈퇴는 `state.users`에서 사용자 정보만 삭제할 뿐, 이 사용자가 속한 그룹의 멤버 정보나 등록했던 지출 내역은 그대로 남음 — 탈퇴 시 연관 데이터 처리 정책이 정의돼 있지 않음
- 게스트가 그룹에서 나가는(탈퇴에 준하는) 흐름은 이 화면과 별개로 정의되어야 함 — 게스트는 `state.currentUser` 개념이 없고 그룹 scope 세션만 있으므로, "회원 탈퇴"가 아니라 "그룹 나가기" 형태가 될 가능성이 높음 (열린 항목)
