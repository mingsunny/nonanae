# 06. 초대코드로 참여

> 참여 성공 시 바로 그룹 내부로 이동하지 않고, 사전 등록된 멤버와 매칭하는 화면([07-join-match.md](07-join-match.md))으로 먼저 이동함.

> ⚠️ **이 화면을 작성할 담당자는 반드시 확인**: 참가자는 정식 로그인 없이도 참여할 수 있도록 결정됨. "로그인하고 참여"는 [01-login.md](01-login.md)의 이메일 회원가입/로그인 폼을 재사용함(**구글·카카오 연동은 스펙에서 제외됨**, 2026-09-12). 계좌정보는 로그인 없이 참여하는 참가자에게 요구하지 않음. 관련 화면: [conventions.md](conventions.md#정식-회원--게스트-참가자).
>
> ⚠️ **sep10 프로토타입 구조 반영 필요**: 이 문서가 가정하던 "닉네임+PIN 경량 세션" 재입장 인증(5회 실패 시 잠금)이, sep10 코드에서는 "이름만 입력하면 계정 없이 참여"로 단순화돼 있고 PIN 검증 로직 자체가 없음. 화면도 `screen-join-group` 단일 화면이 아니라 `screen-join-lookup`(초대코드 입력) → `screen-join-pick`(그룹 멤버 목록에서 "나 고르기" 또는 새 이름/새 멤버로 참여) 2단계로 나뉨. 이 PIN 단순화가 정식 결정인지는 아직 미확인 — 확인되는 대로 이 문서를 sep10 구조 기준으로 다시 작성할 것.
