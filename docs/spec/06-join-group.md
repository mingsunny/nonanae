# 06. 초대코드로 참여

> 참여 성공 시 바로 그룹 내부로 이동하지 않고, 사전 등록된 멤버와 매칭하는 화면([07-join-match.md](07-join-match.md))으로 먼저 이동함.

> ⚠️ **이 화면을 작성할 담당자는 반드시 확인**: 참가자는 정식 로그인 없이 "닉네임+PIN 경량 세션"으로도 참여할 수 있도록 결정됨. 이 화면은 로그인 여부를 체크한 뒤 "닉네임으로 참여" / "로그인하고 참여"(이메일 로그인 또는 구글·카카오 연동) 두 선택지를 노출해야 하고, "닉네임으로 참여" 선택 시 닉네임+PIN(4자리) 입력 → 그룹 내 닉네임 중복 체크 → 기존 닉네임이면 재입장으로 간주해 PIN 검증(5회 실패 시 15분 잠금) 흐름이 필요함. 계좌정보는 게스트에게 요구하지 않음. "로그인하고 참여"는 [01-login.md](01-login.md)의 회원가입/로그인 폼(및 구글·카카오 버튼)을 재사용. 상세 흐름(케이스 D/E)과 근거는 [PLAN-sep03-yunjung.md](../../PLAN-sep03-yunjung.md) "그룹 초대 흐름" 및 "결정된 질문 9·10" 참고. 관련 화면: [conventions.md](conventions.md#정식-회원--게스트-참가자).
