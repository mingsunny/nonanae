# 07. 초대 대기 멤버 매칭

> 초대코드 참여(06) 이후, 이미 그룹에 사전 등록된(앱 미가입 상태로 이름만 추가된) 멤버 중 본인이 있으면 선택해 매칭하는 화면.

> ⚠️ **이 화면을 작성할 담당자는 반드시 확인**: [12-group-invite.md](12-group-invite.md)의 "앱 미가입 상태로 이름만 추가된 멤버(placeholder)"와 [06-join-group.md](06-join-group.md)에서 결정된 "닉네임+PIN 게스트 참가"는 서로 다른 개념이지만 이 화면에서 만남 — 매칭 대상자는 (1) 정식 로그인(이메일 가입 또는 구글·카카오 연동)으로 들어온 정식 회원, (2) 닉네임+PIN 게스트로 들어온 참가자 둘 다 가능함. 두 경우 모두 placeholder 멤버와 매칭되면 placeholder의 지출 기록(`paid_by`/`expense_participants`)이 매칭된 사용자(정식 유저 또는 게스트)의 id로 이관되어야 함. 게스트가 매칭될 경우 이관 후에도 계좌정보는 여전히 없다는 점을 유의. 배경: [PLAN-sep03-yunjung.md](../../PLAN-sep03-yunjung.md) "결정된 질문 9" 참고.
