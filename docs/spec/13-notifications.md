# 13. 알림 (전역 오버레이)

> 그룹 목록 화면(03) 상단 종 아이콘으로 여는 전역 알림 패널. 특정 화면에 속하지 않고 앱 어디서든(그룹 목록 화면에서) 열리는 오버레이.

그룹에서 발생한 새 지출 등록, 신규 멤버 참여 이벤트를 알리고, 눌러서 해당 그룹의 지출 내역으로 이동하는 패널.

- **담당자**:
- **상태**: 초안

## 1. 화면 개요

| 항목 | 내용 |
|---|---|
| 화면 ID | 13_notifications |
| 역할 | 전역 알림 목록 조회 + 해당 그룹으로 이동 |
| 진입 경로 | 03(그룹 목록) 상단 종 아이콘 |
| 다음 화면 | 알림 탭 시 08 화면 이동 (해당 그룹의 지출 탭)|

## 2. 진입 조건

- 로그인한 사용자면 패널을 열 수 있음
- 보이는 알림은 내가 속한 그룹들 것만

## 3. UI 구성

### 3.1 종 아이콘 + 안 읽음 표시

- 03 상단 종 아이콘
- 안 읽은 알림이 하나라도 있으면 빨간 점 표시

### 3.2 알림 패널

- 화면 전환 없이 현재 화면(03) 위에 드롭다운으로 노출(폭 70%, 우측 정렬)
- 헤더: "알림" + 닫기(X) 버튼
- 알림 행: 안 읽음이면 제목 앞에 강조 점, 제목, 시간 라벨
- 정렬: 최신순(새 알림이 맨 위)

### 3.3 알림 종류

- 그룹 내 신규 내역이 등록되었을 때
  - 수정 내역은 알림 발송하지 않음
- 신규 유저가 그룹에 참여했을 때

## 4. 기능

| 기능 | 동작 |
|---|---|
| 종 아이콘 탭 | 패널 열림 |
| 알림 항목 탭 | 읽음 처리 + 안 읽음 점 갱신 + 패널 닫힘 + 해당 그룹 08(지출 탭)로 이동 |
| 오버레이 배경 탭 / 닫기(X) | 패널만 닫힘(읽음 처리 없음) |
