# 14. 비밀번호 재설정

> 신규 화면 — 로그인 기본 수단이 이메일+비밀번호로 확정되면서 필요해짐. 이 화면을 작성할 담당자는 반드시 확인: (1) 재설정 메일 발송 대상 이메일이 존재하는지 여부를 화면에 노출하지 말 것(계정 존재 여부 유추 방지 — [01-login.md](01-login.md) 예외처리와 동일한 원칙), (2) 재설정 토큰의 만료 시간과 1회성 여부. 근거: [PLAN-sep03-yunjung.md](../../PLAN-sep03-yunjung.md) "결정된 질문 10" 참고.
>
> ⚠️ **2026-09-12 업데이트**: 구글·카카오 연동 로그인이 스펙에서 제외되면서, "비밀번호 없는 소셜 전용 계정" 관련 예외 케이스는 더 이상 해당 없음(모든 계정이 이메일+비밀번호). 다만 sep10 프로토타입의 로그인 화면 자체에는 "비밀번호를 잊으셨나요?" 진입 링크가 없어짐 — 이 화면이 MVP에 여전히 필요한지(진입점을 다시 추가해야 하는지) 확인 필요.
