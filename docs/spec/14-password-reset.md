# 14. 비밀번호 재설정

> 신규 화면 — 로그인 기본 수단이 이메일+비밀번호로 확정되면서 필요해짐 ([01-login.md](01-login.md) "비밀번호를 잊으셨나요?" 링크에서 진입). 이 화면을 작성할 담당자는 반드시 확인: (1) 재설정 메일 발송 대상 이메일이 존재하는지 여부를 화면에 노출하지 말 것(계정 존재 여부 유추 방지 — [01-login.md](01-login.md) 예외처리와 동일한 원칙), (2) 재설정 토큰의 만료 시간과 1회성 여부, (3) 비밀번호가 없는 소셜 전용 계정(구글·카카오로만 가입)이 이 화면으로 들어왔을 때 어떻게 안내할지(재설정할 비밀번호 자체가 없음 — "구글/카카오로 로그인하세요" 안내로 대체 필요). 근거: [PLAN-sep03-yunjung.md](../../PLAN-sep03-yunjung.md) "결정된 질문 10" 참고.
