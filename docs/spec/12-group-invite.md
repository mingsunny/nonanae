# 12. 멤버 초대 (그룹 내부)

> 앱 미가입 친구를 이름만으로 미리 추가해 정산에 포함시키는 기능, 대기 중인 친구들에게 카카오톡으로 일괄 초대 보내는 기능이 추가됨.

그룹 멤버 목록을 확인하고, 아직 앱에 가입하지 않은 친구도 이름만으로 미리 추가해 정산 계산에 포함시키는 화면.

- **담당자**:
- **상태**: 초안

## 1. 화면 개요

| 항목 | 내용 |
|---|---|
| 화면 ID | 12_group_invite |
| 역할 | 멤버 목록 조회 + 대기 중(앱 미가입) 멤버 추가/일괄 초대 |
| 진입 경로 | 08/09/10 공용 헤더의 멤버 아바타 줄 탭(08 §3.1 참고) |
| 다음 화면 | 없음 — 뒤로가기로 그룹 상세 복귀 |

## 2. 진입 조건

- 08 §2와 동일한 그룹 멤버 조건

## 3. UI 구성

### 3.1 멤버 목록

- 멤버 리스트: 아바타, 이름, 대기 중 멤버는 "초대 대기 중" 배지
  - 이름 출처: 정식 가입·게스트 멤버는 `users.name`, 대기 중 멤버는 `group_members.pending_name`
- 실제 초대 발송(카카오톡 공유/초대코드 복사)은 이 화면이 아니라 08/09/10 공용 헤더의 상시 노출 버튼에서 실행(08 §3.1 참고) — 중복 방지를 위해 발송 버튼을 여기 다시 두지 않음

### 3.2 대기 중 멤버 추가

- 이름 입력 필드 + "추가" 버튼
- 대기 중 멤버가 1명 이상이면 "대기 중인 N명에게 카카오톡으로 한 번에 초대 보내기" 버튼 노출

## 4. 기능

| 기능 | 동작 |
|---|---|
| 이름 입력 후 "추가" | 대기 중 멤버로 그룹에 추가, 목록 갱신, 토스트("{이름}님을 추가했어요") |
| "대기 중인 친구들에게 카카오톡으로 한 번에 초대 보내기" | 카카오톡 공유 시트 호출 |
| 헤더 back | 그룹 상세로 복귀 |

## 5. 데이터

- 멤버 목록: `group_members`(같은 group_id인 행 전체)
- 대기 중 멤버 추가: 새 `group_members` 행 생성 — `pending_name`에 입력한 이름 저장, `user_id`는 NULL
- 일괄 초대 버튼 노출 여부: 대기 중(`user_id` NULL) 멤버 수 > 0

## 6. 예외 처리

| 상황 | 처리 |
|---|---|
| 이름 입력이 비어있음 | "추가" 버튼 비활성화 |
| 대기 중 멤버가 0명 | 일괄 초대 버튼 자체를 숨김 |
