# 02. 프로필 설정 (최초 온보딩)

- **담당자**: 민선
- **상태**: 작성중

## 목적

카카오 로그인으로 처음 가입하는 사용자가 정산 결과를 주고받을 계좌 정보를 등록하도록 하는 최초 1회성 화면. 이 정보가 있어야 그룹 정산 화면([09-group-settle.md](09-group-settle.md))에서 "누구에게 어느 계좌로 보내야 하는지" 안내가 가능하므로 필수 입력으로 강제한다.

## 주요 기능

- 카카오 로그인에서 넘어온 이름을 입력값으로 자동 채움 (수정 가능)
- 은행 선택 (드롭다운, 공통 은행 목록 사용 — [conventions.md](conventions.md#은행-목록))
- 계좌번호 입력
- 이름 / 은행 / 계좌 세 필드가 모두 채워져야 "시작하기" 버튼 활성화

## 진입 경로

- `screen-login`에서 "카카오로 시작하기" 클릭 → `screen-kakao-loading` (약 0.7초 로딩) → `finishKakaoLogin()`에서 신규/기존 사용자 분기:
  - **신규 사용자** (해당 카카오 계정으로 첫 로그인): 이 화면(`screen-onboarding`)으로 진입
  - **기존 사용자** (이미 `state.users`에 등록된 kakaoId): 이 화면을 건너뛰고 바로 [03-group-list.md](03-group-list.md)로 이동
- 뒤로가기 버튼이 없음 — 온보딩을 완료해야만 다음 단계로 넘어갈 수 있음

## UI 구성요소

- 타이틀: "계좌 등록"
- 안내 문구(guide-callout): "카카오 프로필에서 이름을 가져왔어요. 정산 결과를 주고받을 계좌번호만 등록해주세요."
- 이름 입력 필드 (`ob-name`, text) — 라벨에 "(카카오 프로필)" 표기, 카카오 프로필 이름으로 사전 채움
- 은행 선택 (`ob-bank`, select) — 첫 옵션 "은행 선택"(빈 값) + [공통 은행 목록](conventions.md#은행-목록)
- 계좌번호 입력 필드 (`ob-account`, text, placeholder "예) 1000-1234-5678")
- "시작하기" 버튼 (`ob-btn`) — 세 필드가 모두 채워지기 전까지 disabled

## 데이터

- 이 화면에서 새로 생성되는 `User` 엔티티. 필드 정의는 [schema.md](schema.md#user) 참고: `id`, `kakaoId`, `name`, `bank`, `account`
- 저장 시점: "시작하기" 클릭(`finishOnboarding()`) 시 `state.users[kakaoId] = user`로 저장하고 `state.currentUser`에도 반영
- 현재 프로토타입은 서버 API 없이 메모리 상태(`state`)에만 저장함 — 실제 구현 시 계좌 등록 API 연동 필요

## 액션 & 결과

| 액션 | 결과 |
|---|---|
| 이름 / 은행 / 계좌 입력 또는 변경 | `onObInput()` 실행 → 세 필드가 모두 채워졌는지 검사해 "시작하기" 버튼 활성/비활성 갱신 |
| "시작하기" 클릭 | `finishOnboarding()` 실행 → User 생성·저장 → `afterAuthed()` 호출 → [03-group-list.md](03-group-list.md) 홈 탭으로 이동 |

## 예외처리

- 세 필드 중 하나라도 비어 있으면 "시작하기" 버튼이 비활성화되어 진행할 수 없음 (별도 에러 메시지 없음)
- 계좌번호는 **형식 검증이 없음** — 숫자/하이픈 여부 등 포맷 체크 없이 입력한 텍스트가 그대로 저장됨. 실제 서비스 적용 시 은행별 계좌번호 형식 검증 필요 여부를 정책으로 정해야 함
- 이미 가입된 카카오 계정으로 로그인한 경우 이 화면 자체에 진입하지 않음 (진입 경로 참고)
