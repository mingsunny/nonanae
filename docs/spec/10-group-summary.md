# 10. 그룹 요약 (카테고리별 / 인원별)

> 기존 인원별/카테고리별 토글 방식에서, 두 섹션을 한 화면에 세로로 나열하는 방식으로 변경됨. 그룹 내부 탭 중 세 번째("요약") 탭.

- **담당자**:
- **상태**: 초안

## 목적

그룹 지출을 카테고리별 비중과 인원별 결제/정산 상태 두 관점에서 한눈에 파악할 수 있게 한다.

## 주요 기능

- 카테고리별: 전체 지출 대비 각 카테고리 비중을 하나의 스택바(막대)로 표현하고, 그 아래 범례(색상·이름·금액·비율%)를 금액 내림차순으로 나열
- 인원별: 멤버별로 "결제한 금액"과 잔액 상태(받을 돈 / 보낼 돈 / 정산 완료)를 함께 표시(잔액 = 결제 합 − 부담 합)
- 두 섹션 모두 토글 없이 세로로 순서대로 배치(카테고리별 → 인원별)

## 진입 경로

- 그룹 상세 하단 탭바 "요약" 탭

## UI 구성요소

- "카테고리별" 섹션 라벨 + 카드(스택바 + 범례 리스트)
- "인원별" 섹션 라벨 + 카드(멤버별 행: 아바타, 이름(본인은 "(나)" 표기), 결제 금액, 잔액(받을 돈은 teal 계열, 보낼 돈은 brick 계열로 색상 구분), 상태 라벨)
- 지출이 없을 때 두 섹션 각각 독립적으로 "아직 등록된 지출이 없어요." 안내

## 데이터

- 카테고리별 합계: `Expense.category` 기준으로 그룹핑, 합계가 있는 카테고리만 금액 내림차순 정렬해서 표시
- 인원별: 정산(09)과 동일한 balances(잔액), paid(결제 합) 계산 로직을 공유
- 잔액 표시 규칙: net > 0 → "받을 돈"(teal-deep), net < 0 → "보낼 돈"(brick, 절대값으로 표시), net === 0 → "정산 완료"(금액 자리에 "—")

## 액션 & 결과

- 조회 전용 화면이며 별도의 탭/필터 인터랙션은 없음(과거 버전엔 인원별/카테고리별 토글이 있었으나 제거되고 세로 나열로 변경됨)

## 예외처리

- 카테고리별/인원별 각각 지출 유무를 독립적으로 판단해 빈 상태를 표시(렌더링 로직 자체가 두 섹션으로 분리되어 있음)
