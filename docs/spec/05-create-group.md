# 05. 새 그룹 만들기

> 그룹 생성 후 별도 "초대코드 발급 완료" 화면 없이 곧바로 그룹 내부(08)로 진입함. 초대코드 복사는 그룹 화면 상단 버튼으로 대체됨.

> ⚠️ **그룹 생성은 정식 회원만 가능.** 게스트(닉네임+PIN 경량 세션)는 그룹장이 될 수 없고 초대코드로 참여만 가능함 — 그룹장은 계좌정보·그룹 관리 권한을 갖기 때문에 정식 계정이 필수로 결정됨. 게스트는 애초에 [03-group-list.md](03-group-list.md)에 진입하지 않으므로 이 화면에도 도달하지 않음. 근거: [PLAN-sep03-yunjung.md](../../PLAN-sep03-yunjung.md) "결정된 질문 9" 참고.

- **담당자**: 민선
- **상태**: 작성중

## 목적

정식 회원이 새로운 정산 그룹(여행)을 만드는 화면. 그룹명만 입력하면 즉시 그룹이 생성되고, 별도 단계 없이 바로 그룹 내부로 진입해 지출 등록과 멤버 초대를 이어갈 수 있게 한다.

## 주요 기능

- 그룹(여행) 이름 입력
- 이름이 입력되어야 "그룹 만들기" 버튼 활성화
- 그룹 생성 시 6자리 초대코드 자동 생성
- 생성 즉시 별도 확인 화면 없이 그룹 내부(지출 뷰)로 바로 진입

## 진입 경로

- [03-group-list.md](03-group-list.md) 홈 탭의 "＋ 새 그룹 만들기" 버튼 클릭 시 진입
- 뒤로가기 버튼으로 [03-group-list.md](03-group-list.md)로 복귀 가능

## UI 구성요소

- 상단바: 뒤로가기 버튼, 타이틀 "새 그룹 만들기"
- 안내 문구: "여행 이름으로 그룹을 만들면, 카카오톡으로 함께 간 친구들을 바로 초대할 수 있어요." (카카오톡 **공유** 기능 관련 문구 — 로그인 수단으로서의 카카오와는 별개. 현재 프로토타입에는 실제 카카오톡 공유 연동은 구현돼 있지 않음)
- 그룹(여행) 이름 입력 필드 (`new-group-name`, text, placeholder "예) 제주도 우정여행")
- "그룹 만들기" 버튼 (`create-group-btn`) — 이름이 비어 있으면 disabled

## 데이터

- 이 화면에서 생성되는 `Group` 엔티티 ([schema.md](schema.md#group) 참고): `id`, `name`(입력값), `inviteCode`(자동 생성), `members`(생성자 본인만 포함된 배열로 시작), `expenses`(빈 배열로 시작)
- 생성된 그룹은 `state.groups` 맨 앞에 추가되고, `activeGroupId`가 이 그룹으로 설정됨

## 액션 & 결과

| 액션 | 결과 |
|---|---|
| 그룹 이름 입력/변경 | `onNewGroupInput()` 실행 → 값이 비어있지 않으면 "그룹 만들기" 버튼 활성화 |
| "그룹 만들기" 클릭 | `createGroup()` 실행 → Group 생성 및 `state.groups`에 추가 → 입력 필드 초기화 → 곧바로 그룹 내부([08-group-expense-list.md](08-group-expense-list.md))로 이동 |

## 예외처리

- 그룹 이름이 비어 있으면 "그룹 만들기" 버튼이 비활성화되어 진행 불가 (별도 에러 메시지 없음, 공백만 입력한 경우도 trim 후 빈 값이면 막힘)
- 게스트 계정은 이 화면 자체에 진입할 수 없음 (위 콜아웃 참고) — 서버 구현 시 그룹 생성 API에도 "정식 회원만 허용" 권한 체크가 필요
- 그룹 이름 중복 여부는 검증하지 않음 — 동일한 이름의 그룹이 여러 개 생성돼도 막지 않음
- 사용자가 생성한 첫 번째 그룹인 경우, 실제로는 빈 그룹이 아니라 데모용 멤버·지출·알림이 자동으로 채워짐 (`fillDemoContent`, `seedDemoNotifications`) — 이는 프로토타입 전용 동작이며 실제 서비스에서는 제거되어야 함
